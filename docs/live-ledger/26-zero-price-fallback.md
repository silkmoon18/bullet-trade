# 2026-09-07：缺价成交按0记账

## 用户决策与范围

用户明确要求“没有任何有效数据就记为0”。本次针对已确认归属、方向、成交数量和成交ID有效，但价格资料缺失的成交；不是把缺失数量、ID或费用一律改成0。

只修改服务器记账，不改变策略决策、买卖定价、订单类型或追单机制；聚宽策略、helper和私有JQ配置不需要为本次修改更新。

## 启用与行为

服务器`.data/.env`使用：

```dotenv
QMT_STRATEGY_UNPRICED_FILL_POLICY=ZERO_FALLBACK
```

沿用现有配置入口，只增加一个枚举值。默认STRICT仍拒绝缺价成交；CONSERVATIVE_ORDER_PRICE仍只允许原先的委托价估算。

ZERO_FALLBACK依次尝试：有效成交价；有效成交金额÷数量；满足原有整笔成交条件的有效委托价。都不可用才记录`price_units=0, price_source=ZERO_FALLBACK, price_known=false`。

- 成交数量按回报更新持仓，重复回报不重复入账或重复通知。
- 零价买入不扣本金；零价卖出不增加本金现金。已知佣金/税费仍扣除，未知费用保持未知。
- 飞书成交卡片显示0，并说明“按0记账（非真实成交价），资金/收益不准确”。精确NAV、收益等仍保持未知，不能伪装成真实业绩。
- 不移除资金容量、持仓归属、数量、成交关联等检查。零价买入可能使策略现金高于真实可用现金而再次触发现金不足；零价卖出也不会恢复实际卖回的买入资金。成本失真可能影响止盈止损；均价为0时现有helper跳过基于成本的阈值判断。
- 后续若同一笔已按0入账的成交返回不同有效价格，沿用成交冲突提示，不静默改写历史账本；正确恢复需要独立校正。之前已经估算或真实入账的成交，本次不主动重算。
