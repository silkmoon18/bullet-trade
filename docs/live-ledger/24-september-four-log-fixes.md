# 2026-09-04 日志问题修复记录

## 范围与结论

本次只修复港股ETF漏筛、直连QMT结算周期识别，并只读核实缺失卖出成交价。
不改变开盘last_price参考价、买入/止盈偏移、市价卖出方式、追单方式、先卖后买流程、折价排序或权重公式。
不重置账本、不补下单、不变更策略开关、不部署服务器。

## 港红利漏筛：已修复

- `520890.XSHG`的简称“港红利”未命中原有关键词；指数元数据缺失时会漏筛。
- helper公共过滤方法补充“港红利”和520890代码兜底。没有添加单字“港”，避免误筛港口航运ETF。
- 这是明确的候选池纠错；流动性过滤、日期边界、折价公式、排序、数量和权重不变。
- [基金管理人在上交所发布的公告](https://www.sse.com.cn/disclosure/fund/announcement/c/new/2025-11-15/510880_20251115_YN7A.pdf)列明520890的全名、简称及扩位简称，归属港股通红利低波ETF。

## T+0识别：已修复

- 服务器只读实查：当前QMT板块列表没有`T+0基金`，查询返回空；不是已证明520890为T+1。
- 复用现有`bullet_trade/config/security_overrides.json`的`by_code.<代码>.tplus`，新增520890的`tplus: 0`，可显式设0或1。
- 只读代码级配置，不继承`by_category.fund.tplus=0`，也不按名称、前缀或物理账户可卖总量推断同日可卖权益。
- 无代码配置时仍查询QMT的T+0板块；非空成功结果按日缓存，空结果/异常不再当作成功缓存一整天。60秒后下次查询可重试，未知品种暂按T+1。
- [上交所交易规则第3.1.5条](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)规定适用跨境ETF的当日回转；该代码兜底依据其港股指数属性，不把所有ETF都视为T+0。
- 仍只影响新成交批次；不回溯改写已记账批次的可卖日期。已有9月4日批次到下一交易日已自然解锁。最终卖出仍受策略归属持仓和券商可卖量共同限制。

## 卖出成交价：外部证据缺失，不能伪造修复

服务器仅进行了直连xtquant只读查询，无下单/撤单：9月4日560210卖出的原生`traded_price`、`traded_amount`均为0；对应同标的卖出委托成交均价也为0。不是适配器漏取正数或把负数丢掉。

[迅投官方数据结构](https://dict.thinktrader.net/nativeApi/xttrader.html)将上述字段定义为成交均价和成交金额，但这次模拟柜台未返回有效数值。官方字段存在不等于当前返回值可作为真实金额。

- 保留既有规则：有有效成交金额时按金额/数量取价；严格模式拒绝无价成交。
- 当前启用的保守模式，仅对整笔完全成交的委托使用保护价估算，并保留`price_known=false`，不是确认真实卖出金额。
- 缺价或缺费用时，真实收益指标仍不可确认；佣金/税费未知不伪装成已知0。
- 新增原生零价卖出回归测试，确认不会借用行情价或持仓成本填充真实成交价。
- 没有修改历史资金。若要恢复精确账本，需要该模拟柜台的有效成交/交割记录；未取得前不能宣称这一项已完全解决。
